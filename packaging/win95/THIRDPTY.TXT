Third-party software in DKRR.EXE, the Windows 95 build
=======================================================

DKRR.EXE contains, besides this port's own code (LICENSE.TXT):

  N64ModernRuntime (ultramodern, librecomp), patched -- GPL-3.0, COPYING.TXT.
      Its source and this port's patches to it are in the port's repository.
  fmt                         -- MIT, notice below
  moodycamel ConcurrentQueue  -- Simplified BSD (or Boost), notice below
  nlohmann/json               -- MIT, notice below
  miniz                       -- MIT, notice below
  xxHash                      -- BSD-2-Clause, notice below
  o1heap                      -- MIT, notice below
  GCC's libstdc++ and libgcc  -- GPL-3.0 with the GCC Runtime Library
                                 Exception, linked statically
  mingw-w64's runtime and winpthread, linked statically

Not included: the game's ROM and assets, which you supply, and GLIDE2X.DLL,
your 3dfx card's driver. Nothing from RT64, SDL, Dear ImGui or the online
play libraries is in this build; THIRD_PARTY.md in the repository lists the
modern build's components.

The list was established from DKRR.EXE's symbol table on 3 October 2026
(docs/research/win95-package-licences.md in the repository). Each notice
below is copied from the source tree the build used.
