# DirectX Shader Compiler notice

The Windows build redistributes `dxcompiler.dll` and `dxil.dll` from the
DirectX Shader Compiler binary set pinned by RT64. The packaged compiler is
version 1.7.0.4147; the `dxcompiler.dll` SHA-256 is
`15304A82C8A61DB615A83961D8967A5C468AE7CE77B86D8E9B3DEC60F7AE2166`.
