# DKR-R CRT filter assets

These PNG images are optional display masks. DKR-R composites a selected mask
over the game image only; launcher/overlay controls and performance telemetry
remain above the mask.

`scanlines-soft.png`, `shadow-mask.png`, and `aperture-grille.png` were supplied
from the DK64 Recompiled filter set. The three `Perfect_CRT` images were
supplied by the project owner for inclusion in DKR-R. They are data assets and
are not source code derived from Diddy Kong Racing.

Users may import their own PNG masks. Imported files remain in the user's local
DKR-R configuration directory and are never added to a release automatically.
